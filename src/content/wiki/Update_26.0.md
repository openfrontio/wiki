# 📦 [OpenFront](/OpenFront.io) v26.0 Changelog {#📦_OpenFront_v26.0_Changelog}

## ⚙️ Major Changes {#⚙️_Major_Changes}

- Improved [nation](/Nations) AI.
- [Train tracks](/Railroad) go over rivers.
- Added ability to capture territory from AFK teammates in team games.
- Added feature to delete unit.

## 🗺️ Maps {#🗺️_Maps}

- New Japan map
- New Montreal map

## 🧪 UI & Quality of Life {#🧪_UI_&_Quality_of_Life}

- New build menu
- Background music
- Redesign Player info overlay
