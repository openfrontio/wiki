## Description {#Description}

<figure class="mw-default-size" typeof="mw:File/Thumb"><img src="/images/300px-Bottom_Footer.png" decoding="async" width="300" height="15" class="mw-file-element" data-file-width="941" data-file-height="46"><figcaption>Footer of <a href="/OpenFront.io" title="OpenFront.io">OpenFront.io</a></figcaption></figure>

Discord is the main communication channel chosen by the developers and community.

At the bottom footer on [OpenFront.io](/OpenFront.io) you will find a link to join the official [OpenFront](/OpenFront.io) Discord server. That is where announcements, support tickets, clan recruitment and most community discussion happen. Roles on the server (Content Creator, Contributor, Community Artist and so on) are described on [Community Roles](/Community_Roles), and the rules of conduct on [Community Rules](/Community_Rules).

## Official servers {#Official_servers}

- [**OpenFront**](https://discord.gg/tpFHyfU9gU) — the main server.
- [**OpenFront Masters**](https://discord.com/invite/WhJpgKMQa3) — the official server for tournaments and the competitive circuit (see [OpenFront Masters](/OpenFront_Masters)).
- [**OpenFront Dev**](https://discord.com/invite/K9zernJB5z) — the developer server for codebase collaboration; requires contributor qualifications.
- [**OpenFront Translation**](https://discord.com/invite/fDmWy7jrjA) — the localisation hub for community translations and language support (see [Languages](/Languages)).
- [**OpenFront Wiki**](https://discord.com/invite/ewK4p6uEcX) — the collaboration server for this wiki: documentation, mechanics archiving and game lore.

Community-run servers such as the OpenFront Hub and individual clan servers are listed on the [Links Masterpost](/Links_Masterpost).
