Update 16.0, previously named Update 0.16.0, deployed on the 26 of February, added QoL (Quality of Life) features, improved mobile support and rebalanced mechanics.

## New Features {#New_Features}

- Dark Mode has been added. Enabled, water will be dark blue instead of light blue and ui elements will also be in dark mode.
- A PWA (Progressive Web App) has been implemented.
- There is now a Instructions Menu, below the [Single Player](/Single_Player) Button.
- A new [map](/Maps) has been added: [Mars](/Mars). It is only accessible in private lobbies or single player games, the map won't be selected for public games.
- Two other new maps have been added: [Asia](/Asia) & [Africa](/Africa).
- Multiple new hotkeys:
  - Zoom in: Q
  - Zoom out: E
  - Move camera: W, A, S, D
  - Decrease attack ratio: 1
  - Increase attack ratio: 2
- There is now a map preview (thumbnail) for the public game.
- The leaderboard is now accessible on mobile.
- Toggles for hiding/showing UI elements, emojis and terrain have been added.
- [Nukes](/Nuke) are now highlighted for better visibility.
- [Nukes](/Nuke) now cause more decrease of the population.
- [World](/World) & Europe [maps](/Maps) are more frequent in public games.
- Added a way to watch existing games via a URL.

## Fixes {#Fixes}

- Fixed the "fullsend on boat" bug.
- [Warships](/Warship) now prioritize other [warships](/Warship).
