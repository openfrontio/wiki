# Description {#Description}

The **Hydrogen Bomb** is a missile costing 5 000 000 gold.

It is sent out using a [Missile Silo](/Missile_Silo). It leaves behind [fallout](/Fallout). Its explosion radius completely [irradiates](/Fallout) tiles that are within a distance of 80 and has a high chance to destroy those tiles within a range of 100, using Euclidian distances. This means that if well aimed, the **Hydrogen Bomb** can be used to destroy [SAMs](/SAM_Launcher) without a chance to be destroyed.
