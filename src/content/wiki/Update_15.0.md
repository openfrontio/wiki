Update 15.0, previously named 0.15.0, deployed on the 16th of February 2025, was a big update that took 6 weeks of development.

## New Features {#New_Features}

- Implemented flags.
- Implemented Creative mode. (later changed to options in the single player menu)
- Toggles for [bots](/Bots) & [nations](/Nations) for [single player](/Single_Player) and private lobbies.
- Enabled click on URL to join lobby.
- Multiple UI & quality of life improvements.
- Replaced pngs with svgs for better looking icons.

- Overhaul and redesign for the front page.
- Allow non-hosts to see players in private lobby.
- New OpenFront logo.

- Added [MIRV](/MIRV) (Multiple Independent Reentry Vehicle) nuclear weapon.
- Added construction time for [buildings](/Buildings) (to prevent spamming [defense posts](/Defense_Post) when getting attacked)
- Added 5-second grace period at game start to prevent spawn killing.
- Added keyboard shortcuts: WASD for movement, shortcuts for zoom.
- Implemented new win condition system - conquer 80% of non-irradiated  land to win.
- Added tick counter.
- Combined battleship & destroyer into new "[warship](/Warship)" class.
- Improved leader board to show non-fallout percentage land owned.
- Almost full UI rewrite to support mobile.
- Humans now have distinct color palette.
- Allow brackets in names for alliance tags.
- Names checked for offensive content.
- Public games now use random [maps](/Maps).

## Performance Improvements {#Performance_Improvements}

- Reduced memory footprint by by over 10x (1gb => 60mb).
- Reduced main thread CPU usage by over 70%.
- moved all game logic into a background thread for smoother gameplay.
- now playable on mid-low end smartphones.
