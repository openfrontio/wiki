Update 22.0, previously named 0.22.0 was released on the 25. of April 2025. It increased the team count, made various meta changes and some QoL changes, along with bugfixes and other small improvements.

## New Features {#New_Features}

### Team mode {#Team_mode}

- Players with the same [clan tag](/Clan) will now be sorted into the same team.
- There can now be up to 7 teams in public games.

### Gameplay {#Gameplay}

- Nations will now attack structures with [Atom Bombs](/Atom_Bomb).

- [SAM launchers](/SAM_Launcher) now protect against [MIRVs](/MIRV).
- There is now a multitabbing detection.

### Naval & Combat {#Naval_&_Combat}

- [Defense posts](/Defense_Post) now launch weapons similar to warships, but at a lower frequency.
- When trying to attack a nation that can only be reached through a [transport ship](/Transport_Ship), a [transport ship](/Transport_Ship) will automatically be sent.

### Maps {#Maps}

- A new map has been added: [[Faroe Islands](/Faroe_Islands/)]
- Maps are now categorized

### Customization {#Customization}

- Translations have been updated
- Some flags have been updated
- The user settings have been added to the main menu.

### languages {#languages}

• Arabic

_Note: This is still in Beta of making this section_.

## Bug fixes & Performance improvements {#Bug_fixes_&_Performance_improvements}

- [Transport ships](/Transport_Ship) will now spawn at better locations.
- [Buildings](/Buildings) can no longer be stacked.
- [Warships](/Warship) no longer target [trade ships](/Trade_Ship) within rivers.
- [Warships](/Warship) no longer pirate [trade ships](/Trade_Ship) destined for allied ports.
- Unit rendering has been improved to be more efficient.
- The radial menu can now be closed with right click.
- Screen bounds & transform calculations are fixed.
- An option to anonymise names has been added.
- Enhanced the visual clarity of key inputs in the instructions.
- The radial menu and the player info panel will also update live instead of needing to be re-opened to update.
  - The radial menu will automatically close itself if the tile it was opened from changes ownership.
