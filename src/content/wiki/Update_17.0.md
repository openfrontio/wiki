Update 17.0, previously named update 0.17.0, deployed on the 1 March, was a smaller update, mainly to improve performance.

## Features {#Features}

- The wait time for a new game is now 30 seconds instead of 60 seconds

## Fixes {#Fixes}

- The server has been reworked to handle the influx of new players better
