This Masterpost is here as a list of every useful link concerning OpenFront.

###### **Main links :** _These links are available from the main [site](https://openfront.io/)._ {#Main_links_:_These_links_are_available_from_the_main_site.}

[Discord Server](https://discord.gg/tpFHyfU9gU) This link leads to the main OpenFront Server, you're probably already in it, that's where most of the information is transmitted and where you can easily contact the staff and ask for help/advices or have suggestions/feedback. Also the place to join if you want to help with the [cosmetics](https://discord.com/channels/1284581928254701718/1290379580120502333/1485317025483194398), the UI or the UX.

[GitHub](https://github.com/openfrontio/OpenFrontIO) The link to the game's GitHub main page. As you may already know, OpenFront is an opensource game, meaning that anyone can access the code and submit their contribution to the game, by doing so you access to the Contributor role on the discord server mentionned above along with the Dev discord server. You also gain a free contributor skin that way thus deleting all ads!

[OpenFront's Wiki](/) That's where you currently are! The wiki is in constant evolution and may not be perfectly updated, look below  to contribute to the wiki by joining the OpenFront Wiki Project.

[OpenFront's Reddit](https://www.reddit.com/r/Openfront/) That's where you can interact with a smaller part of the community.

###### Different discord servers related to openfront **:** _Two of these servers are Officials, while the rest is community projects._ {#Different_discord_servers_related_to_openfront_:_Two_of_these_servers_are_Officials,_while_the_rest_is_community_projects.}

[OpenFront Dev](https://discord.com/invite/K9zernJB5z) One of the 2 Official servers, it is for [devs](https://github.com/openfrontio/OpenFrontIO/graphs/contributors?from=28%2F02%2F2026), staff, [content creators](/Content_creators) and translators.

[OpenFront Masters server](https://discord.gg/WhJpgKMQa3) The first and only official OpenFront.io tournament organization. By entering this server, you can access the competitive scene and thus the tournaments plannings while also registering for the future tournaments with your clan!

[Openfront Hub](https://discord.gg/zfTj7dezUV) **The OpenFront Hub** is a community-driven server built by OpenFront players, **for** OpenFront players. The goal is to create a central place for community initiatives, shared information, and collaborative projects. Events, initiatives, and the **OpenFront Awards 2025** were just the beginning and more things are to come as The Hub grows.

[OpenFront Wiki Project server](https://discord.gg/ewK4p6uEcX) This wiki's server, this is where to go if you need to report an error, ask questions, suggest something, etc...

[Openfront Translation server](https://discord.gg/fDmWy7jrjA) Official Translation Server for OpenFront.io. This is where you can report translation misspellings or add a language. When contributing enough to gain the proofreader role, you also gain a Translator role on the main server and a Translator skin in your inventory, thus deleting all ads!

###### **Other variants and links for the game :** _These are sometimes used by the content creators for their videos._ {#Other_variants_and_links_for_the_game_:_These_are_sometimes_used_by_the_content_creators_for_their_videos.}

[https://main.openfront.dev/](https://main.openfront.dev/): One of the devs variants, where the devs try things sometimes.

[https://nightly.openfront.dev/](https://nightly.openfront.dev/): Another dev variant, often used by content creators to test the upcoming updates features.

[https://beta.openfront.io/](https://beta.openfront.io/): Where Evan, Lewis and Nebula (admins) host the playtests before launching a new version of the game.

[https://trade3.openfront.dev/](https://trade3.openfront.dev/): This site doesn't have a cap on economy and tradeships (trade and trade2 don't work anymore for cloudflare reasons).

_Disclaimer for the two following websites: They should only be used when there's trouble or someone knows what they're doing, it is advised to not use them_

[https://blue.openfront.io/](https://blue.openfront.io/): One of the two sites used for smooth updates, so the players don't have their game stop in the middle.

[https://green.openfront.io/](https://green.openfront.io/): The other site used for smooth updates.

###### Other links : {#Other_links_:}

[Steam](https://store.steampowered.com/app/3560670/OpenFront/): The OpenFront Steam release is planned for 2026, make sure to have it on your wishlist.

[https://openfront-tools.frozenpenguin.media/](https://openfront-tools.frozenpenguin.media/): Thanks to [Flopenguin](https://github.com/FloPinguin)  you can now watch the replay of any game, no matter the version it was played on (as long as you have the game url/game ID of course), it also allows you to test a solo game in any past version.

[OFstats](https://ofstats.io/): This site lets you see many information and statistics about players, clans and maps. You can keep track of your progress, but keep in mind that the site only takes into account the name of the player, not the player ID, the stats will be wrong if many people use the same name!

[Map Making](/Map_Making_Guide): Here lies information about how to make maps for the game.

[Patreon](/OpenFront.io) : There is a Patreon were you can subscribe to support the game and get a pretty badge on the discord server!

[Atlas](https://www.openfront-atlas.xyz/map/world/): This website allows you to get additional information on maps, such as Nations spawns

[Twitch](https://www.twitch.tv/iiamlewis): The Twitch account of Lewis (director), where some community events are hosted, some beta playtests and sometimes tournaments.

[Youtube](https://www.youtube.com/@openfrontio): The official OpenFront Youtube account.

[OpenFront Lobbies](https://minhkarl.github.io/) : A way to know what lobby will appear next.
