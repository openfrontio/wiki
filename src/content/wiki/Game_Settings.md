When creating a [single player](/Single_Player) game or a private lobby, game settings can be changed. This includes the selected [map](/Maps), [bot](/Bots) [difficulty](/Difficulty), switching between [FFA](/Free_for_All) and [Teams](/Teams) mode and additional game options.

## Bot Difficulty {#Bot_Difficulty}

<figure class="mw-default-size" typeof="mw:File/Thumb"><img src="/images/300px-Difficulty_Selection.png" decoding="async" width="300" height="65" class="mw-file-element" data-file-width="824" data-file-height="179"><figcaption>The difficulty selection</figcaption></figure>

There are 4 difficulties to select from:

- Relaxed
- Balanced
- Intense
- Impossible

For more information on the difficulties, see [difficulty](/Difficulty).

## Game Mode {#Game_Mode}

<figure class="mw-default-size" typeof="mw:File/Thumb"><img src="/images/300px-Game_Mode_Selection.png" decoding="async" width="300" height="50" class="mw-file-element" data-file-width="826" data-file-height="137"><figcaption>The game mode selection</figcaption></figure>

There are 2 game modes to choose from:

- [Free for All](/Free_for_All) (FFA)
- [Teams](/Teams)

Teams mode is split into several sub-modes:

- 2-7 teams
- Duos (Teams of 2)
- Trios (Teams of 3)
- Squads (Teams of 4)
- Humans Vs Nations

## Additional Options {#Additional_Options}

Different buildings/units can be toggled:

- [City](/City)
- [Defense Post](/Defense_Post)
- [Port](/Port)
- [Warship](/Warship)
- [Missile Silo](/Missile_Silo)
- [SAM Launcher](/SAM_Launcher)
- [Atom Bomb](/Atom_Bomb)
- [Hydrogen Bomb](/Hydrogen_Bomb)
- [MIRV](/MIRV)

The bot count can be set in a range from 0 to 400 and nations can be toggled.

Other options can be toggled:

- Instant Build
- Random Spawn
- Infinite Gold
- Infinite Troops
- Compact Map
- Anonymous Names (replaces player names with memorable animal names, as of [Update 33.0](/Update_33.0))

The game length can be set in minutes from this menu. A custom alliance duration can also be configured (as of [Update 33.0](/Update_33.0)).
