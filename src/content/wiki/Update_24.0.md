[OpenFront](/OpenFront.io) 24.0<sup id="cite_ref-1" class="reference"><a href="#cite_note-1"><span class="cite-bracket">[</span>1<span class="cite-bracket">]</span></a></sup> was released July 18, 2025.

## Major Changes {#Major_Changes}

- Stack units by [building](/Buildings) a unit of the same type on top
- More [ports](/Port) => more [gold](/Gold) per [trade](/Trade_Ship) ship

# 📦 [OpenFront](/OpenFront.io) v24 Changelog {#📦_OpenFront_v24_Changelog}

## ⚖️ Balance Changes {#⚖️_Balance_Changes}

- [Trade](/Trade_Ship) ships are now capped at 150 (Evan)

<pre> → Each <a href="/Port" title="Port">port</a> you own now increases the <a href="/Gold" title="Gold">gold</a> per <a href="/Trade_Ship" title="Trade Ship">trade</a>, counterbalancing the cap.
</pre>

- [MIRVs](/MIRV) have been nerfed

<pre> → Expect less devastating multi-warhead nukes. Land in-between the <a href="/Fallout" title="Fallout">fallout</a> can be more quickly conquered.
</pre>

- [Warships](/Warship) prioritize enemy [transport ships](/Transport_Ship) over [warships](/Warship). Reload instantly after shooting a [transport ship](/Transport_Ship). (Evan)
- [Building](/Buildings) discounts can only be used one time.
- AI [nukes](/Nuke) now avoid [SAM launchers](/SAM_Launcher)

## 🚅 Major Features {#🚅_Major_Features}

- [Trains](/Train) added for new movement mechanics (experimental for private lobbies and single player) (DevelopingTom)
- Factories spawn [trains](/Train) and [railroads](/Railroad) (choose [Factory](/Factory) as unit in private lobby or for single player, to use [trains](/Train))
- [Railroads](/Railroad) can form loops
- Added Trios and Quads. Add them to public lobby rotation together with Duos. (FakeNeo)
- Upgradeable structures: [Cities](/City), [Ports](/Port), [SAMs](/SAM_Launcher), and [Silos](/Missile_Silo) can now be improved
- Multi-level radial menu with dynamic build options
- Creative Commons License added to non-commercial resources
- [Factories](/Factory) added for private lobbies and single player games
- Hash-based routing implemented
- Flares system implemented
- GitHub Releases with release notes are now supported (click the What's New button/megaphone icon)

## 🔧 Game Improvements {#🔧_Game_Improvements}

- Improved territory drawing performance
- [SAMs](/SAM_Launcher) now only target [nukes](/Nuke) threatening nearby areas
- [Nukes](/Nuke) are now faster (speed increased from 4 → 6)
- Better color mixing for small player counts (Ble4Ch)
- Unique player colors to avoid confusion (Ble4Ch)
- Better and optimized [bot](/Bots) behavior and spawn logic (tryout33 & FakeNeo)
- Boat build discounts now scale with unit ownership
- Improved username censoring and management
- Updated [East Asia](/East_Asia) map (formerly "[Japan and Neighbors](/East_Asia)")
- Reworked and optimized leaderboard UI
- Improved visual clarity for [alliances](/Ally) and stacked [buildings](/Buildings)
- Better handling for betrayal alerts and radial menu behavior
- Red alert frame when [betrayed](/Traitor) (devalnor)
- Attack hotkeys added (Engla)
- Boat hotkey added
- [Nations](/Nations) can spawn [cities](/City) without a [port](/Port)
- Team sizes now equalized
- [MIRV](/MIRV) warhead intercepted stats are now recorded
- Text FX added
- [Terrain](/Terrain) manipulation for attack advantage
- New logo added
- Fix Duo partner ([Nation](/Nations)) always same in Single player (tryout33)
- Rename Replay Speed to Game Speed for Single player (tryout33)
- Fix [Nations](/Nations) [building](/Buildings) more than allowed (tryout33)

## 🧪 UI & Quality of Life {#🧪_UI_&_Quality_of_Life}

- Fixed text overflow in UI (Diessel)
- Fixed websocket and join bugs
- Fixed boat-on-land issues
- Fixed modal errors and null pointer warnings
- Fixed input handler edge cases on Mac (proper modifier and emoji key detection) (Ble4Ch)
- Fixed scrollbar appearing unnecessarily in small boxes on Chromium browsers
- Fixed [giant world map](/Giant_World_Map) key
- Leaderboards, alerts, and modals now support translation & dark mode
- New custom flag support and pattern icons
- Various patterns available (Sword, Shells, White Rabbit, Goat, Cats, Hand, Radiation, Cursor, QR)
- Patterned territory support
- More responsive scrollbar and player info panels
- Top bar redesign (Diessel)
- More responsive design for in-game elements
- New icon layer/sprites for structures
- [Building](/Buildings)/loading/HP bars improved
- Proper [alliance](/Ally) timer naming
- Logout button added
- Handle not spawned player fixes
- Multiple patterns support
- Fix: anonymized name isn't displayed in chat message (tryout33)
- Fix Leaderboard: show 0% instead of NaN when all terrain is [nuked](/Nuke) (tryout33)
- Some fixes to the new Radial menu (tryout33)
- Fix bug/performance improvements for [trade ships](/Trade_Ship) (tryout33)
- News Notification Badge for new release notes (floriankilian)
- Translation improvements

## 🛠 ️Backend & Technical {#🛠_️Backend_&_Technical}

- Stats endpoints are now available
- Added CORS origin headers
- Added support for mobile apps native login
- [Discord](/Discord) user and guild member caching
- Improved session error handling
- Changed server logging
- Improved data loading and fixed various bugs

## 🔒 Security & Bug Fixes {#🔒_Security_&_Bug_Fixes}

- Fixed naval attack spam exploit
- Fixed [gold](/Gold) donation validation exploit
- Fixed pot issue
- Various stability improvements and bug fixes
